# License notes — third-party & generated assets

## Demo audio (`public/demo/pianomind-demo.wav`)

The "Try sample audio" button plays a bundled demo file that is **generated by
our own script** (`scripts/generate-demo.mjs`) — a synthesized piano-style
rendition of **"Ode to Joy" (Ludwig van Beethoven, 1824)**.

- The melody is firmly in the **public domain**.
- The synthesized recording was produced by this project's script (no third-party
  performer/recording), so the resulting WAV is safe to redistribute.

To regenerate the file:

```bash
node scripts/generate-demo.mjs
```

We bundle a local file (instead of hot-linking example tracks such as
Wikimedia's "MainTheme with a touch of Nuvole Bianche") precisely so the demo
works without external hosts, CORS, or network access.
